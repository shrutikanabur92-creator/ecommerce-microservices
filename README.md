# E-commerce Microservices Project

## Project Description

This is a beginner-level E-commerce application
developed using Python Flask microservices.

## Microservices

1. Product Service
2. Order Service
3. Payment Service

## Technologies

- Python Flask
- Git and GitHub
- Docker
- Docker Compose
- AWS EC2 Ubuntu
- Jenkins (planned CI/CD integration)

## Application Workflow

1. Customer selects a product.
2. Product Service returns product details.
3. Order Service creates an order.
4. Payment Service simulates payment.
5. Order Service returns order confirmation.

## Deployment

The application runs using Docker Compose.

Command:

docker compose up -d
